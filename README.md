# Tiles-Clock

A simple clock made with virtual tiles, for the poor.

# Compile from source

You need CMake in order to compile it. Go inside the root directory of the project and run theese commands:

Configure the project:
```shell
$ cmake -Bbuild -S.
```

Compile it:
```shell
$ cmake --build build
```

And execute it:
```shell
$ ./build/tiles-clock
```

All done!
